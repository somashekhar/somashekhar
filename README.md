### Hey, I'm Soma 👋

I'm a Staff Software Engineer at **IONOS Cloud** in **Berlin**.
I build IONOS Cloud's sovereign-cloud platform products: **Managed Kubernetes**, which provisions and runs production-ready Kubernetes clusters for customers, and **AI Model Hub**, IONOS's European platform for AI model inference.

- ☸️ **Kubernetes platform:** operators, controllers and reconcilers, cluster lifecycle and migrations, autoscaling
- 🐹 **Go backend engineering:** APIs, microservices, Terraform providers and Go client libraries
- 🤖 **AI agents & tooling:** MCP servers, plus Claude-based agents that automate engineering work such as dependency-update PR triage and spec-driven development
- 🎓 **CKA** and **CKAD** (Linux Foundation, 2021)
- 🧭 10+ years across cloud, networking and e-commerce (IONOS, HelloFresh, Infoblox, Infosys)
